ℹ️ 設計条件・入力ガイド

① 上載荷重 q

・木造2階建て程度の建築物：10.0 kN/m² を標準とします。
・駐車場等の場合：5.0 kN/m² を標準とします。
・その他の場合は適宜設定してください。

② フェンス荷重 (天端)

擁壁天端にフェンスを設置する場合は、風圧等の水平荷重 (kN/m) を入力してください。カタログ値等で確認します。

③ 土の比重 γs

・粘性土：16.0 kN/m³
・砂質土：18.0 kN/m³ を標準とします。

④ 土圧係数 Ka

・擁壁背面を盛土する場合：0.50 を標準とします。
・山留め・切土の場合：0.40 を標準とします。

⑤ 根入れ深さ Df と 前趾土重 W3

・根入れ深さ Df (m) を入力すると、前趾上面に乗る土の重量 W3 = γs × B1 × Df が自動計算され、安定計算の抵抗重量・抵抗モーメントに加算されます。

⑥ 滑動・地盤抵抗の検討

・粘性土：N値等から定めた粘着力 c と底版の摩擦力
・砂質土：内部摩擦角 φ から求めた摩擦係数 μ
・地盤改良：摩擦係数 0.50 を標準とします。

⑦ 適用範囲

・擁壁の見付け高さ Hw ≦ 2.0m 程度を標準とします。
・断面算定がNGとなる場合は、壁厚 tw や底版厚 tb を調整してください。

3. 安定計算

3.1 地盤反力度 (地耐力の検討)

偏心量 e = B / 2 - (ΣMr - ΣMt) / ΣV = {{f(c_B)}} / 2 - ({{f(c_Mr)}} - {{f(c_Mt)}}) / {{f(c_sumV)}} = {{f(c_e, 3)}} m (許容限界 B/6 = {{f(c_B/6, 3)}} m)
※ e ≤ B/6 より、台形分布
最大地盤反力 σ_max = (ΣV / B) × (1 + 6e / B) = {{f(c_sigma_max)}} kN/m²
最小地盤反力 σ_min = (ΣV / B) × (1 - 6e / B) = {{f(c_sigma_min)}} kN/m²
※ e > B/6 より、三角形分布 (底版一部離脱)
最大地盤反力 σ_max = 2·ΣV / (3·(B/2 - e)) = {{f(c_sigma_max)}} kN/m²
最小地盤反力 σ_min = 0.00 kN/m²
最大地盤応力度: {{f(c_sigma_max)}} kN/m² ≦ 許容地耐力 qa: {{f(p.qa)}} kN/m² {{ c_sigma_max <= p.qa ? 'OK' : 'NG' }}

3.2 転倒に対する検討

安全率 Fo = ΣMr / ΣMt = {{f(c_Mr)}} / {{f(c_Mt)}} = {{f(c_Fo)}} (必要安全率 Fo_a = 1.5)
転倒安全率: {{f(c_Fo)}} ≧ 1.50 {{ c_Fo >= 1.5 ? 'OK' : 'NG' }}

3.3 滑動に対する検討

安全率 Fs = (ΣV × μ + c × B) / ΣH = ({{f(c_sumV)}} × {{f(p.mu)}} + {{f(p.c)}} × {{f(c_B)}}) / {{f(c_sumH)}} = {{f(c_Fs)}} (必要安全率 Fs_a = 1.5)

・縦壁高 hw = H_soil - tb = {{f(c_hw)}} m
